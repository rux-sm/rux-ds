Theme creator

Pick a Carbon hue family or fine-tune each token by hex, watch an existing page re-render, and take the CSS block away. The contrast readout is advisory: it warns on a ratio below the threshold a token's own use calls for, and never blocks — theme-creator/scenarios.json says what each token is checked against and why. Further down, Surfaces is a second, smaller tool: pick one of Carbon's own compiled themes and remap just its four resting surfaces — a base for something like an OLED-dark variant, without touching anything else that theme already gets right.

Lowercase letters, digits and hyphens; not white, g10, g90 or g100 — those are compiled Carbon themes, not a surface to layer over.
Applies the same grade-substitution the shipped rux theme already proves — one undoable step, overwriting all twenty fields below.
