# Changes a consumer can see

Consumers link `/rux-ds/…` live at this repository's newest tag, so a release
reaches every app the moment it is pushed — nothing to move, and no chance to
read a changelog first. That is why this file exists, and it records the one
thing a release can do that an app cannot absorb silently: **a class or
component that left.**

**Corrected 2026-09-11.** This opened "consumers pin a tag" until today.
Nothing has pinned since 2026-09-10 (roadmap §8.4, decided §8.6) — and a file
written FOR consumers telling them to do something that no longer exists is
the worst place for that sentence to have survived.
Additions are safe — `docs/coverage.json` only ratchets upward — and are not
recorded here. A removal or rename is one line, newest first, with the commit.

Nothing removed yet.
